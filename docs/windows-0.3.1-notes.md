# 0.3.1 移除允许进程功能

日期：2026-10-15。

按用户要求，移除每条指令的 Windows 允许进程与 Mac 允许应用列表，包括列表列项、搜索条件、编辑框、选择适用程序入口和匹配限制。规则不再需要指定运行程序。

旧草稿、生效配置、历史版本和导入包中的 `scope` 字段加载后不再限制触发；保存或导出配置时不再写出该字段。Quicker 原始条目的进程绑定只作为迁移原文保留，不产生新的允许列表。无需手工清空原来的 `notepad.exe` 等绑定，也无需改写磁盘上的旧配置才能生效。

全局黑名单、总开关、暂停、规则启用状态、焦点与执行代次检查、本程序窗口及已识别的密码/只读控件保护仍有效。移除允许列表不能证明所有目标程序的输入兼容性问题已经解决。

## 使用

先从托盘退出旧版，解压并运行 0.3.1 的 `quicker-text.exe`，在管理页确认规则启用并恢复监听。编辑了草稿时仍需点击“应用设置”。新版继续使用原有应用数据目录。
