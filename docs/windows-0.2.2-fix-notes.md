# Windows 0.2.2 修复说明

版本日期：2026-10-14。配置格式仍为 version 1，升级保留已有规则、范围和黑名单。

## 本次变化

- Windows 键盘监听向有界队列提交实际按键，由工作线程维护短暂的英文缩写缓冲并匹配规则，避免在键盘回调中读取正文或执行动作。
- 目标观察分别提供焦点、可编辑、密码与输入法状态等轻量信息，以及可用时的正文与光标信息。正文不可读取不再直接等同于键盘监听不可用。
- 中文选字仅在完整候选与实际按下的缩写一致时允许 Esc 取消候选。输入法状态未知时停止；英文上屏内容也必须具备安全清除依据，不能按键次数盲删。
- 执行检查目标焦点和执行代次。无法读回正文的输出报告 `unknown`，发送完成不代表目标已处理，剩余步骤停止。
- 管理页突出说明程序范围：`notepad.exe` 只在记事本执行；留空表示所有程序在规则范围内。已有用户规则不会被自动改成所有程序。
- 运行状态优先显示实际按键输入的目标检查信息，正文观察仍保留在高级详情中。动作编辑说明区分可读回与不可读回的发送路径。

## 验证记录

前端 `npm run build` 通过。React Doctor 全量检查为 86/100，与改动前一致，保留两项既有告警：`App.tsx` 控制流复杂度、`CaptureTemplate.tsx` 根据属性更新状态。变更范围检查因仓库没有 `HEAD` 无法运行，使用全量检查核对。`cargo test --workspace` 最终共 137 项通过、1 项依赖私人导出样本的测试跳过、0 项失败。

按用户要求，完成修复后未进行键盘、鼠标实测。因此未验证英文与 Microsoft 拼音在记事本、聊天编辑框和 Codex 编辑框的真实替换结果，也未实机验证程序范围、黑名单、密码框、焦点切换与候选状态变化。旧版 0.2.1 的记事本测试不能替代本版本验收。

## 使用边界

Windows 当前只支持即时触发，结束键模式不自动执行。配置总开关、暂停、规则启用状态、进程范围与黑名单仍有效。输入法、编辑控件或权限级别无法确认时可能拒绝，不保证所有程序通用。

可读取正文的路径继续核对正文和光标。不可读回路径与粘贴、HTML、文件和图片发送的结果可能为未知；请查看目标输入框。已发生的输入、点击或打开无法自动撤销；复杂多步骤与延迟指标尚未完成实机验收。

绿色版配置保存在当前用户应用数据目录，升级前应导出配置并保留旧版 exe。免安装不表示配置随 exe 移动。

发布构建：cargo build -p quicker-text --release 成功，可执行文件版本 0.2.2。独立评审已关闭本轮确认的问题；未进行新版本实机输入验收。
