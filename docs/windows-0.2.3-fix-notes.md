# Windows 0.2.3 修复说明

版本日期：2026-10-14。配置格式仍为 version 1，沿用用户已有规则、程序范围和黑名单。

## 本次变化

- 候选无法读取时不再一律停止，加入按键兼容模式：仅当整段连续、未中断的 ASCII 英文字母输入匹配完整缩写时，按每个实际字母一次 Backspace 清除，再输出操作文字。不等待候选读取，不承诺数字或标点缩写走此模式。
- 兼容模式自动使用 Backspace，即使规则或全局设置选择 Esc 也如此；Esc 仅用于已经确认完整候选对应缩写的路径。能读取正文和候选时继续使用较详细的核对路径。
- 仍检查启用、暂停、规则范围、黑名单、焦点、可编辑、密码保护、配置代次及状态新鲜度。候选状态未知本身不阻止兼容模式；目标或可编辑状态无法确认仍停止。
- 运行状态显示“候选无法读取，使用按键兼容模式”，不再把候选未知解释为暂停匹配；编辑页解释兼容模式与 Esc 设置的关系。
- 兼容模式输出结果为 `unknown`：软件按实际按键做尽力替换，但聊天编辑器可能自定义 Backspace 行为，发送完成没有证明缩写已删除或目标已接收。已经发生的输入无法自动撤销。

## 使用边界

Windows 当前只支持即时触发，结束键模式不自动执行。生效进程填写 `notepad.exe` 仍只在记事本触发；需跨程序使用的规则可自行将范围留空，保存后应用设置。升级不会自动更改范围。

兼容模式依赖实际按键连续性，不能把所有编辑器或输入法都视为已验证兼容。焦点切换、暂停、修改配置或输入被打断会使该段输入失效。结果未知时需查看目标输入框；复杂多步骤与延迟指标没有实机验收。

绿色版配置仍在当前用户应用数据目录，免安装不表示配置随 exe 移动。

发布记录：cargo build -p quicker-text --release 成功，可执行文件版本 0.2.3。绿色包内可执行文件与编译产物的 SHA256 一致。
