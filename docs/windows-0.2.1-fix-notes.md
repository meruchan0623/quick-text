# Windows 0.2.1 修复说明

版本日期：2026-10-14。提供 Windows x64 免安装绿色版；配置格式仍为 version 1。

## 本次变化

- 操作类型拆成“粘贴纯文本”和“键入纯文本”。前者通过剪贴板一次粘贴整段文字，后者逐字输入；来回切换保留正文及文件来源。底层仍保存 `type: text` 与 `method: paste/keys`，兼容已有配置。
- 编辑窗口说明补充用途、填写示例与操作步骤，替换底层实现术语；原 Quicker 私有动作明确不能执行，只保留导入信息。
- Windows 文字观察支持 TextPattern，不再只接受 TextPattern2。使用实际焦点窗口对应的输入法状态；拿不到可靠状态时继续拒绝。
- 输入法候选可在完整候选与输入的缩写一致、原有正文未变时按 Esc 清除后替换。Microsoft 拼音插入的音节分隔符，如 `t'h'x`，只有实际按键序列能证明对应 `thx` 时才进行匹配。候选中的部分后缀不作自动删除。
- 修复软件写入剪贴板后，把自身引起的变化误判为外部修改、导致删掉缩写却没有粘贴的问题。剪贴板暂时被占用时会短暂重试；恢复原内容前会核对归属和内容，避免覆盖其他程序刚复制的文字。
- debug 可用 `QUICKER_TEXT_DATA_DIR` 保存隔离测试规则；release 忽略该变量，仍使用当前用户应用数据目录。debug 的模拟键盘特许不进入 release。

## 已取得的验证

- Codex 内置浏览器：两个独立操作选项可见，切换操作后正文保留。
- Computer Use：debug 专用测试模式允许模拟键盘走真实 Windows Native 路径；记事本 + Microsoft 拼音输入 `t`、`h`、`x` 后显示 `t'h'x`，软件取消候选并粘贴 `Thanks very much.`，已看到目标正文正确。
- 英文路径在较早构建中已经识别并删除 `thx`，随后暴露剪贴板错误；补丁后尚未重新完整测试英文替换及逐字键入。用户要求停止继续键鼠测试并打包，不标记这些项目通过。
- 前端 `npm run build` 通过；`cargo test --workspace` 共 129 项通过、1 项依赖私人样本的测试跳过、0 项失败。

## 仍需注意的范围

Windows 只支持即时触发。结束键模式不自动执行，空格、Tab、回车等正常输入。密码、只读输入框、无法确认或过期状态会拒绝。TextPattern 可读取并不代表所有浏览器、输入法或特殊输入框兼容。

键入逐字检查目标文字和光标；如果目标发生变化会停止。粘贴、HTML、文件或图片发送后仍可能显示结果未知，这不代表粘贴失败，也不证明接收成功。复杂多步骤、英文最终补丁、逐字最终补丁、其他浏览器/输入法及 release 实机复测尚未全面验收。

免安装并不意味着配置随 exe 移动：规则仍在用户应用数据目录。新版本沿用该目录，升级前建议导出配置并保留旧版 exe；不要把调试配置混入正式规则。
