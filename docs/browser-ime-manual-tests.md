# 浏览器与中文 IME 手测矩阵（0.2.0）

这是待用户执行的验收说明，当前没有浏览器或中文 IME 的实机通过证据。新增路径仅接受控件提供的可靠 UIAutomation TextPattern2 文本、光标和 inactive composition 证据；不能推断 Chrome、Edge、所有网页或所有中文输入法均支持。任何字段不可确认、采样过期、密码、只读、非折叠选区或组合中状态，安全目标是拒绝匹配，保留原输入。

## 准备与记录

1. 安装本轮 0.2.0 开发包，导出原配置备份；0.1.0 包保留用于回退。保持暂停，创建仅测试进程生效的合成规则 `qtzzx` → `测试🙂`。先 keys 后 paste；每次改动保存并应用，记录 revision。
2. 用要验证的浏览器打开仓库 `scripts/fixtures/browser-input.html`（本地文件即可）；仅使用合成正文。网页无外部依赖，不保存输入，事件记录不含正文或密码值。
3. 用真实物理键盘输入。外部模拟注入会被过滤，不能作为自动匹配验收。测试中切回管理窗口会改变焦点；记录之前目标的 provider/阻止原因及采样时间，不把管理窗口状态当网页状态。
4. 每项记录 Windows 版本、应用/浏览器版本、输入法名称/版本、输入源、控件 ID、权限、revision、输入步骤、期望/实际及截图或视频。不在证据中放工作正文、密码或剪贴板敏感数据。

## 矩阵

| ID | 控件或步骤 | 通过条件 |
|---|---|---|
| B01 | input、textarea，US ASCII 即时；Space/Tab/Enter 模式另测透传 | 即时仅可靠 provider 执行；结束键模式不执行，键正常透传，无吞键。不将透传算消费功能通过 |
| B02 | contenteditable 的纯文本、跨 span/b 节点、光标移到中间 | 只在文本/光标/组合状态可靠时匹配；保留无关前后文和格式，无法确认时拒绝 |
| B03 | maxlength=5，输入恰好五字符的缩写 | 不能根据收到按键推断实际正文；不误删。目标限制导致输出截断需如实记录，不认作输出通过 |
| B04 | readonly、disabled、password | 不执行替换，不吞触发键；密码字段不读取/记录正文 |
| B05 | 选中部分或全部缩写、按方向键/Home、点击其他位置 | 旧 buffer 清除，选区/光标改变不追删旧词 |
| B06 | 页面第3次input移焦/移光标 | 放弃旧事务，不在新位置删除、不打错控件 |
| B07 | 页面每次input转大写、80ms后追加“异” | 真实上屏文本为准；变更使旧 observation/generation 无效，不错删脚本新增内容 |
| I01 | 中文 IME 候选完整提交后的合成中文即时触发词；结束键模式另测透传 | 须匹配此前已观察候选且正文未变，并取得可靠 inactive composition + 文本/光标证据；结束键模式不执行。其他提交或证据不足拒绝，不能宣称通用中文支持 |
| I02 | 拼音候选未上屏、候选取消、按 Esc、半上屏后继续组合 | 活动/未知 composition 不自动执行，不自动清除候选；不把拼音键序列当正文。目标自定义 Backspace 可能产生首步副作用，读回失败应停止后续 |
| I03 | 新规则继承 global；global Esc→Backspace；显式 escape/backspace 旧规则 | 新规则保存 null/缺省继承；改 global 后继承规则随之变化，旧显式值不变；本版策略不会启用组合中执行或自动清候选 |
| I04 | 中文→US→中文切换、第三方输入法、IME开关、网页重载 | 不沿用旧采样；支持状态和拒绝原因可核对。第三方输入法无证据就拒绝 |
| S01 | 触发前后持续输入、切窗、取消、草稿应用/revision改变 | 旧事务不追删、不打错窗口；已发生副作用如实报告 |
| S02 | keys/paste/HTML 输出 Unicode、emoji、多行；慢粘贴并复制新内容 | 输出逐字核对；新剪贴板保护和延迟读取单独记录，unknown 不是目标已消费成功 |

出现错删正文、吞错键、输入到错误窗口或覆盖新复制任一项，立即暂停，保留步骤、版本和匿名证据；修复后重跑相关矩阵。未提供 provider 的目标安全拒绝属于边界符合，不能计作该目标的功能支持通过。

## 尚未完成的实质差距

- P1/T01/T02/T04：浏览器各版本/provider、中文输入法的可靠 composition 与 caret 真实证据；UIAutomation 只读观察本身不证明终止键消费或替换安全。
- T05/T07/T08/T09/T18/T19：实际目标消费、继续输入/切窗竞态、剪贴板新复制/延迟读取、物理持键冲突及声明跨窗转换。
- T16/T17/T20：全部高级 GUI/三 dialect 往返、真实键布局、多屏/DPI/Retina/录制回放完整系统验收。
- 原计划常用功能完整候选、任意窗口/IME切换、Quicker专有上下文/私有动作仍需专门adapter/逐项映射；没有任意动作1:1承诺。
- macOS 完整链接/安装包/实机权限和输入、签名/公证、Windows安装升级回退实测、短keys p95<100ms及paste/HTML基线仍未完成。

本版最终边界、Shift释放／超时限制和首轮浏览器即时规则步骤见 [Windows 0.2.0手测](windows-0.2.0-test-notes.md)。结束键不自动执行，不将早期计划中的消费目标作为本版支持项。


Windows 0.2.0 keys（包括手动动作测试）需要可靠UIAutomation provider，按 Unicode 字符发送（emoji 的 UTF-16 代理对同批），每字符前后核对新鲜目标与预期正文前缀，并有界等待消费；正文或光标改变即停止后续。所有路径的paste／HTML／文件／图片发送后返回 unknown 并停止剩余步骤，不证明目标已接收。手动测试不能跳过键入provider检查；自动替换中需要核对正文的快捷键及非导航按键发送后也会unknown停止后续；手动独立快捷键没有该自动替换限制。复杂多步骤不作为完整交付／实机验收通过。
