# 0.4.0 团队话术、图片粘贴与新手提示

日期：2026-11-09。

0.3.1 之后的第一个正式版本，汇总以下改动。

## 新功能

- 团队话术：从 TSim 客服系统下载、缓存并定时同步团队话术，默认开启；同一缩写时团队话术优先于我的指令；话术中的图片一并同步；可在本机单独停用某条话术，或复制到我的指令。
- 粘贴图片：新增「粘贴图片」动作与图片资源库，编辑器可选择并预览图片。
- 配置导入导出：导出改为 ZIP 配置包，导入支持 ZIP、JSON 与 Excel（.xlsx）话术表，并提供 Excel 填写模板。
- 新手提示：输入缩写的前两个字符后，屏幕右侧短暂列出可用指令，只提示、不替你选择。默认打开，可在「设置 → 新手提示」关闭或调整显示时长（1–10 秒，默认 2 秒）。
- 应用内检查与下载更新。
- 文字与按键组合改为按键录制；编辑、删除、批量操作保存即生效。

## 界面

- 设置页合并；列表页顶部压缩，团队话术的同步信息并入搜索栏，分组与批量操作合为一行。
- 界面改为柔和的青绿风格，新增应用图标；托盘单击打开管理界面。

## macOS

- 启动时请求缺失的系统权限，授权前等待而不判为故障；不再因输入法或非 ABC/U.S. 布局暂停监听。
- 一组与 Windows 行为对齐的按键、焦点与 Electron 应用修复。

## 升级说明

- 新版继续使用原有应用数据目录；首次写入前会把旧配置备份到 `backup-pre-0.4/`。
- 之前手动关闭过「输入时显示候选提示」的，升级后会重新打开，需要时在设置里再关一次。

## 验证

- `npm run doctor`：类型检查、lint、格式与 680 项前端测试通过。
- `cargo test --workspace`：通过。
- CI、installers 与 release 工作流（试运行）在 `main` 上通过。

真实键盘、中文输入法与各聊天软件的现场输入仍需在本版上验收。
