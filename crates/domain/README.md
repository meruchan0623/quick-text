# quicker-domain

Pure Rust domain model, configuration compilation, three independent parsers, preflight preparation, and safety transaction helpers. JSON fields use snake_case and `type` tags. The authoritative contract is `src/model.rs`; schema version is 1. This crate contains no hook, injection, networking, or text-content logging.

## Public entry points

- `compile_config(&Config)` validates an active snapshot. `CompiledConfig::match_input(input, terminator, foreground)` returns the longest eligible match, breaking ties by config order. Matching respects enable flags, case, configured word separators, global blacklists, immediate/terminator modes, and effective terminators. It does not read files or clipboard.
- `parse_sendkeys`, `parse_inputscript`, `parse_replay` preserve their own dialect and source spans. `parse_dialect` dispatches explicitly. Parsed source remains on `ActionPlan.source`; structured operations are authoritative when edited through forms. There is no promised textual serializer for ambiguous legacy syntax.
- `validate_plan` rejects unknown schema, invalid coordinates/keys, excessive operations/waits, and unpaired held keys/buttons. `scale_replay` applies delay/speed exactly once; the host must not scale the prepared plan again.
- `preflight_action` reads files with explicit encoding, renders trigger-time variables, parses B text, validates the complete plan, and verifies static clipboard file/image sources before trigger erasure. A native decoder must verify the full image and freeze assets before erasure; checking a signature cannot prove the entire image is valid.
- `expand_reusable(action, config, context)` performs preflight and expands enabled rule IDs as portable actions. It rejects unknown/disabled IDs, cycles, nesting above 16, non-scalar parameters, and expanded plans above 10000 operations. Named values use `{param:name}`; JSON scalar types remain typed until rendering.
- `Transaction` checks revision, input generation, focus, cancellation, timeout, IME safety, and permission before erasure and each step. It records deletion once, sent operations, consumption uncertainty, and known side effects. `cleanup` releases owned keys only when their physical state is explicitly known up. The host must call the guards around every native operation and track actual physical state.
- `ClipboardLease::can_restore` compares the host clipboard generation before restoring. It does not implement clipboard ownership or format backup itself.
- `DraftStore::apply` compiles and increments revision, invokes a host publishing callback, and accepts only the requested acknowledgement. On failure the old active configuration and pending draft remain. The host must restore durable publication/engine state when acknowledgement fails.
- `import_package` previews JSON packages/configs. Invalid or unsupported entries are disabled; unknown fields/action variants are preserved as raw JSON in `unresolved` and as visible disabled rows. Imported automated actions are disabled until reviewed. Persist `unresolved` and use `export_package_with_unresolved` to retain them across export. `merge_import` implements reject/replace/keep-both ID strategies.
- Native Quicker TextCommand JSON arrays (optional UTF-8 BOM) use a typed PascalCase adapter and then the same validation/review policy. ActionType values verified from the installed Quicker.Common QuickActionType enum are 0=None, 2=SendKeys, 3=PasteText, 6=InputText, 7=InputScript. Other values require rewriting. TextCommand reflection verified TriggerKey=0 as immediate and null as no per-command key; standard Windows keys 9/13/32/186 map to tab/enter/space/semicolon, with other codes retained disabled. BindingProcessName is ignored because program restrictions have been removed; its original value is retained as migration metadata. Legacy native rule scope fields are accepted on read and omitted on save. Source flags, title/group, case, IME erasure, parameter conventions and optional notifications map to the existing model. Unknown fields, malformed types, conflicting parameters, unsupported regex/scripts/date templates and FILE: sources remain disabled. Text template validation supplies synthetic clipboard/selection values without capturing user data; unsupported date tokens and unavailable reusable parameters require rewriting. Every original entry, including compatible entries and LastUpdateTimeUtc, is retained in `unresolved` as migration metadata; its status distinguishes compatible retention from failures. Native package reimport does not reexecute the array conversion.
- `export_espanso_subset` exports only the declared safe literal/inline text subset and lists incompatible rules/global settings; it never edits an unmanaged Espanso configuration.

## Implemented semantics and boundaries

SendKeys B accepts Ctrl/Shift/Alt symbols, Enter, grouped modifiers, supported named keys up to F16, repetitions, and documented literal punctuation/brace escapes. Modifiers retain Ctrl instead of being rewritten to Cmd. Nesting is limited to 32. Unknown or unsupported keys fail. Plain characters remain Unicode text; variable values are escaped as literals by default. Explicit syntax values must be opted into in `VariableContext.syntax_variables`, then fully parsed. A modified non-ASCII/punctuation literal that lacks a reliable named-key mapping is refused.

Inputscript covers all 21 planned commands. Only the first colon is split; Windows drives and text colons survive. Comments and `;;` step separators are recognized. `input2` supports documented tab and paired CRLF escapes. Undocumented escapes, lone LF escapes, mixed percent/pixel coordinates, and ambiguous literal separators fail with diagnostics; structured text bypasses those legacy ambiguities.

Replay covers MV/MD/MC/MU/MH/MW/DL/KD/KU/KP/MVD, semicolon plus tab spacing and standalone tab separators, no-move coordinate sentinels, original negative coordinates, and strictly positive finite speed. Empty DL arguments are supported; undocumented DL payloads and one-axis missing coordinates are rejected pending actual source-tool verification. No coordinates are automatically scaled.

Default parameters use the complete matched text. First-capture mode requires an existing and participating group. Capture templates percent-encode only substituted UTF-8 values, once; literal percent sequences in the template remain unchanged. Explicit null differs from an empty fixed string. Unsupported .NET lookaround/backreferences are retained in import reports and require rewriting.

Text source encodings: UTF-8 (optional BOM), UTF-16LE/BE (optional matching BOM), GBK without replacement. Content files are bounded at 16 MiB, parser sources at 1 MiB, image signature checks at 32 MB. Numeric .NET date fields, fractional seconds, quoted literals, escapes, AM/PM, and fixed offset timezone formats are supported. Locale-dependent names such as MMMM/ddd are rejected instead of guessing a locale. Selection must be explicitly supplied; it is never assumed globally readable. Template output is interpolated once, with generated placeholder-looking text left literal.

This crate does not claim native injection acceptance, IME capture, clipboard format acceptance, arbitrary target text consumption, official Quicker encrypted package/database import, private Quicker bridge execution, or operating-system signed delivery. Host adapters and real target-application tests must establish those capabilities.

## Verification

`cargo test -p quicker-domain` exercises rule boundaries, ignored legacy program restrictions, blacklists and priority; capture/null/template semantics; all three parser corpora; 21 inputscript commands and 11 replay opcodes; unknown syntax and source preservation; variables/file decoding; reusable actions and cycles; revision/focus/generation/IME/clipboard guards; draft publish failure; package round trips and unknown-entry preservation. Synthetic fixtures are in `tests/fixtures`; mouse/keyboard script corpora must be reviewed before an explicit native run.

Parser references verified on 2026-10-14: https://getquicker.net/KC/Help/Doc/inputscript and https://getquicker.net/kc/help/doc/playrecord. Tests use synthetic text only.

`cargo test -p quicker-domain --test quicker_import` covers native numeric actions, immediate/inherited/key trigger modes, ignored process bindings and fields, automation review, malformed/unknown entries, duplicate IDs, regex/script validation, BOM and retained-original round trips. An ignored external-sample test can be run with `QUICKER_IMPORT_SAMPLE` set to a local Quicker export and `cargo test -p quicker-domain --test quicker_import externally_supplied_quicker_sample -- --ignored`; the supplied 53-entry sample passed (50 paste, 1 input text, 2 disabled SendKeys, all immediate). No customer text fixture is included in this repository, and this proves domain import rather than native target input acceptance.
