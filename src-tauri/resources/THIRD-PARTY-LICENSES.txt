QT-THIRD-PARTY-LICENSES-PLACEHOLDER

Quicktext - third-party licenses (placeholder)

This file only exists so that `cargo build`, `cargo test` and `tauri build --no-bundle` work from a
plain checkout (tauri-build fails when a bundled resource is missing). It is NOT the notice file.

The release workflow (.github/workflows/release.yml) overwrites it with the generated file
(scripts/generate-third-party-licenses.ps1) before building the installer. The installer build
(scripts/check-bundle-preconditions.ps1, run by Tauri before bundling) and the packaging scripts
(scripts/package-artifacts.ps1, scripts/package-portable.ps1) refuse to ship it while the marker on
the first line is still present, and refuse to run without the dependency source archive.
Never commit the generated file.
